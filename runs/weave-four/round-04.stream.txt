I reverse‑engineer directly from the **target tape itself** rather than guessing machines:

1. **Extract the execution trace.** In a TM exactly one tape cell changes per step, so the symmetric difference of consecutive target rows is a singleton `p_t` (head position at step `t`). From that I get:
   - `p_t` – head column,
   - `r_t = tape[t][p_t]` – symbol read,
   - `w_t = tape[t+1][p_t]` – symbol written,
   - `mv_t = sign(p_{t+1} − p_t)` – direction moved (the last move is unobservable and is resolved by consistency).

2. **Recover the state sequence.** A TM is a deterministic transducer, so two time indices `t, t′` in the same state must have identical `(read, write, move, next‑state)`. I run partition refinement over the trace to obtain the minimal consistent state labelling (equivalent to DFA minimisation for the observed input string).

3. **Build the table.** Each state is emitted as two 3‑char tokens (read 0 and read 1); unobserved symbols become `---` (fewer defined transitions = better tie‑break). States are named `A, B, C…` in order of first use, with the state at time 0 forced to `A`.

4. **Fallbacks.** If any row diff is not a singleton the code still emits the best trace‑consistent machine rather than crashing.

    beh = {}
    for t in range(n):
        b = sid[t]
        d = beh.setdefault(b, {})
        rr, ww, mm = r[t], w[t], mv[t]
        nb = sid[t + 1] if t + 1 < n else None
        if rr in d:
            e = d[rr]
            if e[1] == -9 and mm != -9:
                e[1] = mm
            if nb is not None:
                e[2] = nb
        else:
            d[rr] = [ww, mm, nb]

    distinct = []
    for t in range(n):
        if sid[t] not in distinct:
            distinct.append(sid[t])
    letter = {sid[0]: 'A'}
    for b in distinct:
        if b not in letter:
            letter[b] = chr(ord('B') + len(letter) - 1)

    trans = {}
    for t in range(n):
        b = sid[t]
        L = letter[b]
        rr = r[t]
        e = beh[b][rr]
        ww, mm, nb = e
        Lnb = letter[nb] if nb is not None else None
        key = (L, rr)
        if key in trans:
            cur = trans[key]
            if cur[1] == -9 and mm != -9:
                cur[1] = mm
            if cur[2] is None and Lnb is not None:
                cur[2] = Lnb
        else:
            trans[key] = [ww, mm, Lnb]

    for L in letter.values():
        for rr in (0, 1):
            if (L, rr) in trans and trans[(L, rr)][1] == -9:
                trans[(L, rr)][1] = 1

    # --- serialise state rows in A,B,C... order ---
    parts = []
    for b in distinct:
        L = letter[b]
        row = ''
        for rr in (0, 1):
            key = (L, rr)
            if key in trans:
                ww, mm, Lnb = trans[key]
                if Lnb is None:
                    row += "%d%s%s" % (ww, 'R' if mm > 0 else 'L', L)
                else:
                    row += "%d%s%s" % (ww, 'R' if mm > 0 else 'L', Lnb)
            else:
                row += '---'
        parts.append(row)
    return '_'.join(parts)
